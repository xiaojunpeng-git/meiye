# 第67轮：参团付款成功后停留支付页

## 根因

拼团支付接口接收临时结算号，并在创建真实订单后返回新的 `result.order_id`。会员端此前继续使用临时号查询支付结果，真实支付与入团已经成功时仍会收到“订单不存在”，因而停留在支付页。

## 修复边界

- 支付接口返回真实订单号后，支付页立即将其设为本次唯一查单与跳转标识。
- 富友支付、回调、订单入账、成团、权益及历史业务数据不变。
- 待确认状态继续只查服务端权威订单，不会再次发起支付。

## 验证

`payment-order-identity.mjs` 直接执行生产 Vue 的 `goPay` 方法，覆盖临时号发起支付、真实号查单以及重复点击只查单不二次付款。测试使用合成响应，不连接支付网关或业务数据库。
