# 员工看板实际岗位与人员下钻：开发候选

日期：2026-11-06。状态：开发与自测完成后提交产品经理验收；尚未 commit、部署或 push。

## 本轮范围

- 美容师人数按有效实际岗位名称“美容师”精确统计，不读取手艺人资格推断岗位。岗位选项由当前范围内实际岗位生成。
- 员工总人数、在职人数、美容师人数、期间流失人数、岗位条目、学历各档、年龄各档、工龄各档带后端下钻条件，进入人员管理的看板明细模式。
- 汇总、人员明细、分页及导出共用唯一人群选择器。按员工去重，多店和多岗位不重复计算同一人；各岗位可分别包含兼岗员工。
- 下钻沿用已查询的组织、日期、岗位条件；返回保留条件。未提交筛选草稿不改变已显示数字的下钻条件。
- 人员管理资格在后端独立验证；个人数据范围只返回本人，不因入口授权扩大到同店其他员工。
- 日期标题读取实际查询期间，替代硬编码“2026年8月”。

## 业务边界

当前在职人员来自启用员工档案、有效门店任职和有效岗位关系。历史日期不重建历史在职快照；日期用于年龄/工龄截止日和期间离职事实。跨店员工的年龄/入职日期沿用授权范围最小任职 ID 的代表档案；明细使用相同代表记录。未填写年龄或入职日期不进入对应分档。期间流失按 leave 事实去重，调店、停职不计入，可包含已重新入职人员。岗位历史名称仍读取现有岗位表，与原数据能力一致。

金额、经营业绩、目标和编制算法保持原路径，本轮不恢复缺失档案、不修改资格或生产数据。截图示例的生产人数未在本轮连接线上复核；本地 707 仅为本地对账证据，不代表现网最终人数。
