# R99 平台请货复制范围修复候选

- 基线：`f86c37675a77857a40da29456b0fd9c9c9334d94`。
- 现象：平台请货列表成功返回 131 条；点击门店发起单据的“复制”后，详情接口提示“单据不存在或当前账号无权查看备注”，全表被列表错误位遮住。
- 代码根因：平台请货列表同时包含总部和门店请货；复制动作无条件把 `row.location_id` 写入总部仓范围。门店发起单的该字段是门店仓 ID，后端总部仓校验拒绝该详情。
- 修复：仅当原单的仓库身份是总部且其 ID 属于当前授权总部仓列表时切换总部读取仓；门店单保持当前合法总部仓。复制详情异常独立提示，不再遮住已成功加载的列表。
- 权威源及边界：原单和明细仍由库存请货详情接口按登录身份与仓库权限读取；本修复只更正读取上下文和前端错误展示，不写库存事实、不更改历史单据、日期、金额或权限。
