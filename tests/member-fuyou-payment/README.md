# 会员端富友统一支付契约

验证范围：

- 会员端“微信支付、支付宝支付”均进入富友，不回退原生支付接口。
- APP、小程序、H5 对富友返回的付款码或链接有明确处理。
- 富友回调校验商户、签名、本地订单金额，并且只有本地幂等入账成功才返回成功。
- 后台只展示统一富友在线支付入口，原生微信和支付宝配置入口不可见。
- 会员收银台和支付方式校验使用富友完整配置作为统一开关。
- 富友要求的20位数字渠道单号与本地业务单号独立映射，回调按映射还原并核对业务类型、金额。
- 普通浏览器微信支付不索取公众号 OpenID，支付失败明确提示且确认按钮防重复提交。

运行：

```bash
./tests/member-fuyou-payment/run-static.sh
```
