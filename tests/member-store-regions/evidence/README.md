产品经理确认将“门店实际地区筛选”作为第3轮并授权开始开发。开发基线为 b50fd1f13d32c157ccd13e6ef63fb139d5d09702；相关既有源码开工前无未提交改动。本目录 fixed-version.json 标识待验收固定版本，不提前创建业务提交。

## 本轮新增

- 门店地区不再使用全国地址字典弹窗，按同一门店查询范围提供实际省、市、区。
- 复用原进店隔离、常用会员门店、名称搜索、商品及子卡适用范围，不建立第二套门店权限查询。
- 全部地区、全省、全市、区县；直辖市省级节点使用全市文案。搜索、附近排序及原选店回调不改。
- 地区选项不受列表当前页限制，只输出地区ID/名称，不向前端返回全量门店电话或坐标。
- 加载、失败重试、无地区提示，关闭取消草稿及异步旧响应丢弃；长地区名称不挤占搜索框。
- 缺少有效省市区ID或字典父子关系不一致时，提示地区待完善，不猜文本地址、不回填主表。这些门店仍在原可选范围内的“全部地区”可见。

## 既有功能回归

- 原普通门店列表字段、分页、计数响应、单店详情/配送配置、距离排序路径保持原实现。
- 原首页选店、购物选店、预约选店事件回调及预约 is_all 模式保持。
- 收货地址等共用 areaWindow 未修改；收银、主题、订单支付、会员归属、卡项权益均不改。
- 严格复用原后端规则，本轮不是取消隔离门店、放开全部商品可售或调整进店权限。

## 自测和证据

- contract.cjs：真实SFC模板/脚本，省市区/全部、直辖市、关闭/重试、并发顺序、API参数及原选店事件。
- regions.php：真实控制器、服务、DAO和本地MySQL；仅上下文依赖使用测试夹具。地区字典批量一次读取，超过20家门店的地区不截断，同名区县不串联、常用用户与匿名隔离、商品/子卡交集、关闭/删除/隔离门店、无匹配与无适用门店、整数计数旧响应及分页/单店返回回归。
- 数据库夹具仅使用连接级临时表，结束释放后核对原始门店表整体摘要不变；不修改现有门店或地址。
- browser.cjs：真实HBuilderX H5编译包，320/375宽度完整交互与边界；地区HTTP响应和外部微信SDK为边界夹具，不能冒充真实数据库业务验收。
- real-browser.cjs：真实H5→真实本地API→本地MySQL，无API数据替换，选择江苏/扬州与API查询结果一致。只替换非微信浏览器的外部SDK初始化；不绕过登录或权限。
- build.cjs：当前正本HEAD加本轮3个会员端文件冻结树的小程序本地构建。由现有标准构建器输出008会员端校验包，不上传。运行时桥接、全部JS解析、WXSS等价还原、客户域名/AppID及包体上限检查通过。
- 编译存在既有组件key/分包建议及project.config.json重复输出警告；最终产物AppID、域名和所有包大小由独立合同检查，警告不等于已验证模拟器。
- 本轮未进行微信模拟器或真机交互验收，尚不能声称小程序真机验证通过。

## 数据架构自检

- 权威源为门店主表省市区ID，名称及父子关系为本地地区字典；不是门店经营组织/经营大区。
- 粒度为当前可选门店对应的去重地区路径，仅查询投影，无交易、金额、事实、事件、统计时点、Outbox或历史快照写入。
- 普通列表与地区投影走同一范围路径；地区只去掉自身地区条件与分页，不去掉其他限制。无跨用户/跨客户缓存。
- 已存ID优先，坏数据仅提示，不自动迁移、不改历史资料。无schema迁移及生产回填。
- 不涉及资金、库存、核销或资源写入，事务锁、幂等和冲销不新增；数据库测试自身采用隔离临时表保护原业务数据。
- 当前每次投影一次门店字段查询和最多一次批量字典查询；没有按每家门店扫描全国字典或N+1查询。EXPLAIN见mysql-result.txt，未为本轮额外改库建索引。
- 本地历史数据确有地区未完善记录；这不能推断008现网有相同数量。线上数据完整性核对与修正不在本次本地开发范围内。
