## 功能入口与模块

1. 平台端、门店端、商家端各有一个左侧中间悬浮入口，按当前登录身份的入口权限显示。平台管理员在 AI 窗内配置客户 SiliconFlow API 与主动连接测试；密钥不回显、不存设备历史。
2. 设备会话模块：设备保存历史，账号/实例分区，24 小时有效；每次发送最近 20 个完整问答轮次。同步兼容路径只在当前 HTTP 执行内使用正文；可靠异步路径将最少执行输入加密保存于实例私有临时存储，队列与运行表只保留任务引用和无敏感状态，执行结束、取消、过期或重复确认后立即清理，最长不超过 24 小时。浏览器未运行时不能清理设备历史，下次加载先淘汰过期历史。
3. 业务执行模块：注册能力、计划编译、Workflow 执行合并管理；只执行已登记的指标与只读查询。业务筛选未登记时拒绝，不自动删除条件。前端 Run 视图在设备；后端仍保留必要的取消、幂等、并发、预算与证据元数据，不能把设备历史当作执行授权。
4. 统一查询和证据模块：复用报表指标与权限、同批一致读、不可变结果、精确金额展示；模型不计算、不发 SQL、不获取真实经营数字。当前以确定性模板渲染，不依赖模型自由编写结论。
5. 文件与运行治理模块：统一 XLSX 底座的 AI 来源分区、父子任务取消、文件内容校验、仅文件失败降级、24 小时清理、费用用量和运行状态。
