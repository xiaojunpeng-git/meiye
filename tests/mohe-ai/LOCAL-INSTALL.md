## 实际启动检查

加载真实 ThinkPHP 和本地数据库后，直接调用网关 bootstrap（无业务权限的测试上下文），返回 `enabled=false`、`configured=false`、`history_round_limit=20`，目前就绪指标为 `consume_amount`。该检查不冒充登录用户，也不构成 HTTP 鉴权或业务验收。

发现并修复：ThinkPHP 容器会递归注入可空构造依赖，导致尝试无 DSN 构造 PDO。HTTP 入口须显式 `new AiGatewayServices()`，可选依赖注入仅用于隔离测试。

首次网关初始化在服务端受控私有 runtime 下生成用于签名/加密的随机密钥；该密钥未进入源码、日志或本记录。

后续复核：运行工厂已使用数据库服务器 UUID、当前 schema 与受控实例配置派生实例标识；在实际 `mohe-platform-app` 再次加载通过，未配置模型。平台 HTTP 入口已改用既有 `Setting.apiBaseURL`，不再误把开发站点的 SPA HTML 当作 API；平台 `18093`、门店 `18091` 的无登录 bootstrap 均返回受控 JSON 与 `Cache-Control: no-store`。商家 `8080` 路径缺少移动协议头时被既有协议门禁拒绝。这些检查不代表已登录用户问数通过。
