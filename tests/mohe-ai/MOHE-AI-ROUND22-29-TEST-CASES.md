# 魔核 AI 长期回归测试用例（已收录至第 50 轮）

> 版本日期：2026-09-28
>
> 文件路径沿用原名，避免既有方案与证据链接失效。
>
> 覆盖范围：经营问数的自然语言理解、注册指标绑定、统一查询、上下文、回答呈现、Excel 异步任务、登录失效及安全失败。
> 用例性质：这是长期验收设计，不是某一次线上部署的通过证明。每条用例均须按当前固定版本重新执行并留存结果。

## 1. 重组原则

1. 同一能力只保留一个主用例；日期、数量、对象替换作为该用例的变体，不再拆成多条重复用例。
2. 第 30—50 轮产品经理实际提出且曾答错、答不出或超时的问题，均保留为“真实问题回归”锚点；原句不改写成代码规则。
3. 预期由“对象 + 注册指标 + 时间 + 结果形态”定义，真实姓名、门店、金额和人数只在当次真人验收中对账，不写死在用例内。
4. 确定性快捷路径仅可在注册表能唯一证明对象、指标、操作与日期时使用；不确定的问题仍必须由模型理解或请求澄清。

## 2. 通用前置与判定

| 编号 | 要求 |
| --- | --- |
| P-01 | 使用同一固定源码版本的后端、执行 worker 与平台前端；真人测试使用已登录的授权账号。 |
| P-02 | “今天、本月、最近 30 天”等相对日期由服务端 `Asia/Shanghai` 可信业务日解析。 |
| P-03 | 对账以同权限、同范围、同期间、同注册指标的统一 Reader/报表为准；前端和模型不得自行计算经营值。 |
| P-04 | 真人测试保留问题链、统计日期、页面用时、Run 状态、回答形态和对账结论；不得删除失败 Run 或把夹具通过冒充真人验收。 |
| P-05 | 答案必须显示统计期间；金额面向用户按元整数展示，内部计算与导出仍保持分精度。 |

### 通过与失败判定

- **查询成功**：对象、指标、范围、日期、排序/条件及结果形态均正确，且与统一 Reader 对账一致。
- **安全失败通过**：未完整理解或无完整数据能力时，不查询删减后的问题、不伪造 0 值/名单，并说明真实限制或可执行的下一步。
- **性能通过**：确定性问题不无故进入模型；模型问题受总等待预算限制；Excel 生成不得阻塞屏幕答案。

### B. 对象、指标与时间语义

| 编号 | 输入与上下文 | 预期结果 | 核对重点 | 来源 |
| --- | --- | --- | --- | --- |
| MHAI-B01 | “今天销售业绩第一名是谁？”；变体：“今天劳动业绩第一名是谁？” | 人员 / `staff_sales_yeji` 或 `staff_labor_yeji` / 今天 / 前 1 排行 | 销售与劳动指标不互换，不误用整店经营指标。 | R22—29 |

| MHAI-B03 | 指定授权门店/会员问业绩；同名员工问业绩 | 指定对象汇总；同名人员进入带门店标签的澄清 | 名称只能通过授权目录精确绑定；不得静默选中同名对象或扩大范围。 | R22—29 |
| MHAI-B04 | “某员工的销售业绩和劳动业绩怎么样？” | 同一人员、两个明确指标、同一期间的汇总 | 人员可同时是两个事实的归属者，不能用互斥岗位身份裁剪。 | R22—29 |
| MHAI-B05 | “这个月的销售额最高是哪天？” | 日期对象 / `sales_amount` / 本月 / 前 1 日期排行 | “最高”必须作用于销售额和日期对象；不得回答成门店第 1 名。 | R37 真实失败 |
| MHAI-B06 | “销售记录最多的项目是哪个，最低又是哪个？” | 项目 / `sales_record_count` / 同期的最高与最低结果 | 同时保留 max、min 两个操作及项目对象；不得改成销售额、门店排行或只答一半。 | R37 真实失败 |
| MHAI-B07 | “2026年3月到今天，最高营业额是哪个门店”；在新对话及连续对话中执行 | 门店 / `cash_performance` / 2026-03-01至服务端业务日 / 前1排行；直接读取完整期间内已有记录 | “营业额”是现金业绩；不只抓取“今天”，不缩短期间，不因接入起点要求确认，也不附加历史数据未接入提示。无记录时明确暂无数据。 | R50 小程序真实答错；补充口径 |

R50补充B07变体（不另建重复用例）：

- “从今年三月一直到今天”“2026年3月份至今”“去年十二月到今天”“2025年3月到5月”；核对中文月份、跨年和终点省略年份。截图当天业务日为2026-09-27，原句预期03-01至09-27，运行时不写死今天。
- 可查询期间对照：“2026年9月到今天，最高营业额是哪个门店”“从今年九月一直到今天营业额最高是哪个门店”；与同权限统一Reader核对日期、指标和结果，记录页面及服务端耗时，不固定门店名或金额。
- 对象换成会员、员工、项目、产品时，使用各对象注册允许的指标验证同一日期规则；不能把门店现金业绩机械复制到所有对象。
- “春节到今天”“开业至今天”“三月初到今天”等未完整解析的边界不得被残留“今天”覆盖；非法日期、反向区间仍拒绝。额外“扣除退款”条件不得因营业额别名而被删除。
- 原句早于历史接入起点时仍直接使用原区间；加入全区间无记录的变体，不将未发生记录的期间伪造为有业绩。

### G. 登录失效、等待结束与安全重试

此组与 F04 的模型超时分开：登录或传输失败不等于模型正在计算。失效凭据、断网和延迟响应优先使用受控测试或夹具；不得为测试修改生产登录有效期、使真实用户下线或清空历史记录。

| 编号 | 操作与变体 | 预期结果 | 核对重点 | 来源 |
