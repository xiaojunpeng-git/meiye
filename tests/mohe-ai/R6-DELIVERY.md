## 功能与实际边界

1. 基础配置：沿用客户 SiliconFlow 配置，密钥不回显、留空不更换；被动运行概况与主动连接测试区分，主动测试明确确认费用。
2. 能力目录：读取源码注册的场景、Skill、Workflow、Tool，不在页面创建 SQL、DAO、指标公式或权限。
3. 场景与引导：保存场景名称、目标、试问样例、3～5 轮上限、未决条件顺序与提示语。样例用于维护试问清单，不是自动训练模型或新增语义别名。
4. 工作流：已登记流程的启停、允许导出与预算收紧；查询、证据校验、确定性渲染顺序不可删改，不支持自由代码或任意拖拽执行图。
5. 试问：草稿预览不调用模型和经营事实；明确确认后真实试问使用已发布版本、真实模型和当前账号报表权限，支持引导、取消与 Excel。轨迹只向当前平台维护者返回。
6. 版本：保存草稿 → 校验 → 发布；并发修订冲突不覆盖；回滚生成新版本，旧版本不可改写。新 Run 固定管理版本，已有 Run 不随发布漂移。

悬浮入口只负责问答，已移除配置表单。配置权限与报表数据权限仍独立。菜单隐藏不是安全边界；后端每次管理操作重新核验真实账号，撤权立即拒绝。

## 产品经理操作顺序

1. 用平台 `admin` 打开【设置 → 魔核 AI】。
2. “基础配置”查看已配置模型；无需重复输入现有密钥。
3. “场景与引导”修改提示语或引导上限，保存草稿。
4. “版本管理”查看差异、校验并确认发布。
5. “试问验证”先做无费用的草稿预览，再确认真实试问；真实试问可能产生客户模型费用。
6. 如需恢复，选择历史版本回滚或恢复源码默认配置。不要把保存草稿当作已生效。
