# 魔核 AI：第零阶段基础合同测试

沟通编号：MOHE-AI-00001。此批次是正式开发后的基础合同实现，不是完整 AI 功能交付。

## 执行

在源码根目录运行 `bash tests/mohe-ai/run-all.sh`。可用环境变量 `MOHE_TEST_PHP` 指定 PHP 可执行文件。

测试加载真实合同类及必要的既有类声明，不启动 ThinkPHP，不读取 `.env`，不连接数据库、Redis、SiliconFlow，不启动 Worker、不创建导出文件。

| 模块 | 测试 | 本批次覆盖 |
|---|---|---|
| 统一指标与报表能力登记 | metric-contract.php | 字典白名单、稳定说明哈希、指标就绪拒绝、终端/指标/形态/粒度精确映射 |
| 运行预算与容量策略 | runtime-contract.php | 默认180秒/最高300秒、澄清冻结、循环与调用上限、接纳判断、容量错误归类 |
| 共享导出来源合同 | export-source-contract.php | REPORT/AI来源不可变、派生分区、双层query、归属和最早到期 |
| 模型计划输入边界 | plan-contract.php | 严格JSON、重复键、候选归属、日期与指标限制、禁止DAO/公式/未绑定范围 |

运行脚本还对新增PHP做语法检查，并执行既有集团报表稳定性、订单中心统一导出两组静态回归。

## 不属于本批次已实现的能力

- 尚无可用 AI HTTP 接口、前端悬浮窗或真实模型调用。
- 输入校验器不是计划编译器；候选归属输入必须由未来可信服务生成，不能直接相信前端。
- 预算与容量策略是纯函数，不提供持久化、事务原子预留、物理执行槽证明、真正取消或进程停止。
- 指标注册不是权限授予；尚无经对账的指标查询 Provider、权限解析器、可重放一致读。生产 `ai_query_ready` 保持 false。
- 导出来源策略未接入既有 Task/Worker/CLI；未执行来源迁移，未开启 AI 导出。只测试来源部分，不代表 claim 租约、取消和发布已实现。
- 通用业务筛选、一次澄清交互、Evidence、确定性答案、Excel写入与24小时完整清理仍待后续实现与真实联调。
- 夹具通过不等于Q001–Q003真实报表对账通过，也不等于Cursor独立业务验收。

## 后续接入门禁

1. 解决既有实际业绩口径及消耗指标映射差异，落实共享查询、权限与版本化一致读；不得在AI层另算一套。
2. 将预算扣减、Attempt、generation、幂等、接纳预留和状态变更接入原子持久化，验证并发和真实停止。
3. 编译器、候选签发、Skill/Tool白名单、Evidence和发布守卫接通后，再逐项开放已验收能力。
4. 导出全入口来源守卫、迁移和发布屏障完整实现并验收前，不创建任何AI导出任务。
5. 保持项目原验收门禁；本地自测不替代Cursor独立验收，不授权提交、部署或push。

代码语法按PHP7.1可用特性编写；本批实际执行环境为PHP8.5.8，不能据此声称生产PHP版本兼容性已验证。
