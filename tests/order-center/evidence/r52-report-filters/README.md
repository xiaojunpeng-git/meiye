# R52 门店订单管理动态统计筛选

## 范围

门店端订单管理九个页面：全部订单、消费订单、充值订单、退款记录、欠款管理、服务记录、补交记录、赠送记录、卡操作记录。使用既有统计查询组件，日期、更多筛选、查询及正常/全部保留在顶部；根据各页后端字段元数据动态加载全部获准筛选字段，不再固定为业务类型、订单号、来源三项。全部订单真实契约有51个可筛选字段，业务日期在顶部，其余50项在默认收起的更多筛选面板内滚动。其他页分别使用自己的字段集，不能复用全部订单字段。关键词、设置、重置撤下；退款操作移入新栏，保留原权限、点击处理函数。平台只读入口、报表下钻约束与数据中心报表不变。

动态字段以 capabilities.filter 为准，剔除隐藏、停用或未授权字段；不将 defaultQuick 当作筛选白名单。文本使用包含匹配、金额/数值使用上下界、日期时间按对应控件提交，枚举保留稳定值；字段新增无需修改页面固定列表。后台字段白名单仍是查询的最终约束。

原列表、分页、业务操作、权限与后端查询服务沿用；原有高级筛选 OR/AND 关系保持，只有主动清空筛选才清除高级条件。空来源仍提交 is_null；业务类型仍在 topFilters，保留后端前置收敛。导出只读取成功执行的查询，不读取未提交草稿。
