## 数据架构自检

- 权威业务源仍为接口返回的员工头像。这里只变更当前基础资料的显示投影和默认图片资源，不涉及历史报表、组织范围、岗位权限、业务事件、经营事实、金额或统计时点。
- 复用已有蓝色和粉色 PNG，通过模块 import 纳入前端资源包；实际开发页默认头像为内置 `data:image/png`，不请求数据库默认值或后端 `/static/images/staff` 图片地址，不复制另一套图片源码。
- 空值及加载失败显示蓝色默认图；已保存的历史男女 PNG/SVG 默认标识仍兼容。自定义上传图片继续保留原地址及既有 API 来源解析，不因为加载失败而覆盖员工/表单数据。
- 新建表单沿用稳定 `/static/images/staff/avatar_male.png` 标识以满足现有保存契约，实际展示使用内置图。正常保存仍提交稳定标识或上传原地址，不把构建哈希、资源包 URL 或内置默认图 data URI 写入主档。
- 图片 error 只修改当前 img 的展示，默认图再次失败不无限重试；未进行批量回填或业务写库。没有新增事务、幂等写入、Outbox、冲销、迁移、快照或索引需求；接口权限与分页不变，默认图解析不增加业务查询。
- 本轮仅本地开发及只读页面验证。客户目标、线上迁移、生产备份与回滚点均不适用；没有 SSH、远程接口写入、真实上传或部署。已有图片选择器为正常预览加载原媒体 URL，不执行服务器操作。
