## 完成范围

- 从商品列表某一状态页签和页码进入已有商品编辑页时，暂存当前页码、每页条数、状态页签和全部已提交筛选条件。
- 编辑页保存或点击返回进入商品列表后，一次性恢复上述状态，并按原页重新查询。
- 商品列表由 `keep-alive` 缓存；最终版在 `activated` 生命周期中统一消费并恢复一次性状态，避免保存返回时先恢复、随后又被 `activated` 重置为默认页。
- 同步 iView Tabs 的激活键，使“仓库中”等视觉高亮和实际查询类型一致。
- 暂存只存在于当前浏览器标签页的会话存储中，列表读取后立即删除。刷新列表或从其他模块进入列表不会继承旧状态。
- 仅已有商品编辑路由触发保留；新增商品不改变原有返回行为。

## 产品经理复测问题与修复

- 产品经理在“销售中”第 3 页修改商品后保存，发现没有回到第 3 页。
- 原因是初版只在 `beforeRouteEnter` 恢复状态，而缓存列表随后执行的 `activated` 又把查询恢复为路由默认值；此前只用“返回”验证，未覆盖最终代码的真实保存路径。
- 最终版把恢复动作放入 `activated`，让保存和返回都在最后一个会改写列表查询的生命周期内恢复。
