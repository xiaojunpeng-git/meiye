# 第44轮拼团大屏、分享归属与会员推广

本目录记录唯一源码正本中的本地开发与自测。产品经理已批准开发；本轮尚未取得固定候选验收、提交、推送或线上部署授权。

## 已实现口径

- 大屏展示成团业绩、未成团业绩和总业绩；金额来自真实已支付订单减成功退款。成团只移动金额分类，不重复增加总额。失败尚未退清的金额仍属于未成团，并单列“失败待退款”。
- 个人、门店、活动排行及明细、导出共用同一后端查询。日期按支付日期；金额内部按分精确计算，页面按元取整。
- 新拼团订单冻结当前分享会员及其所属门店；分享资格由现有推广规则验证。购买/履约门店与推广门店分别保留，不修改员工表或永久分销上下级。历史无分享快照不猜测归属。
- 会员“我的推广”新增拼团推广，服务端只查询当前登录会员的分享订单，展示活动的成团、待成团、失败数量及明细。
- 新版共用会员编辑器读写既有 `spread_open`、`is_promoter` 字段；严格接受 0/1，未提交时保留原值。
- 团长赠送、第三方支付记账详见相邻 `r44-leader-rewards`、`r44-third-party-accounting` 目录；两者属于本轮已确认方案。
