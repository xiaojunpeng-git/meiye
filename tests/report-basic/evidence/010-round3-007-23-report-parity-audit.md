- 007 现场已逐一真人点击这 23 张报表并复核稳定表头：配置报表中的 19 张弹窗和侧栏 4 张页面。弹窗切换瞬间可能暂留上一表的数据和列；所属门店服务数、未消耗明细及实时明细均重新打开等稳定后复核，不用中间态作结论。本地 007 只读 SQL/服务核对用来解释行粒度和公式；其配置哈希与现有来源快照吻合，但不冒充现网 SQL 哈希。
- 010 查询区统一沿用现有“更多筛选”，不移植 007 的旧筛选控件。查询、列表、合计、导出继续共用后端授权事实。产品经理 2026-10-30 后续明确：所有报表统计日期统一取 V3 业务日期；007 用原下单/创建时间的旧逻辑在此项上被覆盖。
- 产品经理已确认：员工销售数按成交时**完整销售人数**均分，筛选只缩小结果。010 的员工报表按查询时当前门店任职展示，调店前的历史任职不追溯；旧事实仍保留在事实层。当前本店无有效任职者不进入相应员工表，双店任职不能靠无条件连接重复计额。

- 金额按项目统一规则在界面显示整数元，底层保留分。007 已知的跨店串算、重复充值、跨月同日号混算等旧 SQL 缺陷不复制到 010；这些需要用统一事实对账后解释数值差异。
