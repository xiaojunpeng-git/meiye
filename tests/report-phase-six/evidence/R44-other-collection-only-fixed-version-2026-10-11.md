# R44 其他收款报表固定版本

## 范围与口径

- 产品经理本轮确认：只按已结账的收款方式“其他收款”筛选；不要求体验标记，也不按金额过滤，0 元记录保留。
- 原“现金业绩”列替换为“应收金额”和“其他收款”：前者取每件商品正式结账的成交应收；后者取历史实际分摊或新口径已提交的结算金额，按商品分摊，不冒充现金业绩。零金额保留。
- 同一商品有多笔“其他收款”时，明细逐笔显示，商品应收合计去重，其他收款合计逐笔累计。历史分摊行沿用原手动补充键，新口径使用结账方式与商品的稳定键。
- 列名取值来源改为业务语言。门店权限、成功整单作废排除、服务端合计、查询与导出共用同一报表服务。
- 产品经理本轮页面确认移除“单价”：列表、导出、列名解释和编辑表单不再提供该列；保存接口同步拒绝新写入，既有补充记录不物理删除。领取日期、领取数量、备注保持原样。
