# 服务记录手艺人调整专项合同

本套件只验证订单中心服务记录的手艺人调整契约，不进入收银流程，
不创建订单，不执行退款、作废或真实服务记录修改。

```bash
bash tests/service-record-craftsman-adjustment/run-all.sh
```

覆盖范围：

- 编辑入口和保存复用服务记录详情权限。
- 复用现有手艺人分配弹窗，修改原因使用第二个独立窗体。
- 消耗业绩按分精确分配且合计等于项目核销金额。
- 工资项目数以半项整数保存，支持 `0.5` 且报表合计不截断。
- 原员工业绩事实以 reversal 冲销，新分配以 forward 追加。
- 调整具备版本、幂等、原因、操作人、时间和前后快照。
- 调整写域不包含会员权益、核销次数、订单和退款主表。
