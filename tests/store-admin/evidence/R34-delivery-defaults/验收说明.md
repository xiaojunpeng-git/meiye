# 第34轮 门店配送默认到店

用户明确要求：配送方式默认勾选到店自提，默认配送方式选择到店。完整新建表单及组织页快捷新增统一delivery_type=["2"]、default_delivery=2；编辑门店已有配送配置为空时使用相同默认，已有有效选择正常回显，不批量修改历史门店数据。接口数组/逗号字符串及数值radio回显兼容。

配送联动按当前组件真实值1快递、2自提、3同城判断。当前默认方式仍被支持时保留，避免勾选自提被错误切回配送；取消某类型后默认方式限定到仍支持的类型。无同城选项才重置同城渠道，避免只选同城被旧2/3判断误清。

仅两个平台前端文件，未改变后端字段、权限、金额、门店权威资料、保存接口或数据库。API仍通过既有storeUpdateApi保存，数据在用户点击保存后才提交，本轮不替用户自动保存。已有门店历史事实与配置不回填；无迁移、远程连接或线上操作。

自测：真实SFC函数与方法执行，核对新建、空配置编辑、已有快递/自提配置、字符串数值回显、勾选切换、同城渠道、新建快捷入口以及真实handleSubmit传出的两项字段。HTTP保存请求用模拟传输截取，不声称数据库保存/刷新验收。两个Vue2模板编译和JS解析通过，限定差异空白检查通过；无永久新增测试或打包产物。
