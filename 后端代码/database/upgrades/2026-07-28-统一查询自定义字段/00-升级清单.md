## 权威数据与粒度

- 会员、订单、余额、库存等原业务主表仍是业务权威源；本包不写入或回填任何经营数据。
- unified_query_preference：一行一个“租户 + 账号 + 页面”的查询设置正本。
- unified_query_custom_field：一行一个稳定自定义字段当前态；field_key 永不因改名变化。
- unified_query_custom_field_version：一行一个字段版本，不覆盖历史表达式，并冻结引用字段类型／权限合同。
- field_alias_set / field_alias：账号页面级改名版本及明细，只改变显示名和导出表头。
- field_reference：一行一个保存查询、报表或导出任务对字段版本的引用。
- export_task：一行一个后台导出任务，冻结受控查询计划、字段版本、表头、截止日期和数据时点。

查询设置与自定义字段是技术元数据，不产生销售、服务、收款或其他经营事实，不写业务事件和 Outbox。相关 command 必须在 manifest 中登记为明确 eventless，原因为“账号查询偏好／报表定义元数据变更，不改变业务权威数据”。

## 事务、并发和历史

- 外层命令继续使用 query_preference + member_list 账号级资源版本和命令幂等。
- 共享字段另以 current_version 条件更新，防止不同账号同时编辑时互相覆盖。
- 别名集合有独立条件版本；查询设置内部版本只作审计递增，并发由外层资源锁唯一负责。
- 停用会保留所有版本和引用，并阻断未开始导出；归档只允许在引用全部释放后执行。
- 已成功生成的导出保留冻结表头和结果，不因后续改名、停用或归档重写。
- 只有 running 导出任务可持有 lease token 和到期时间；pending、成功、失败、阻断、过期任务必须同时清空两项，避免任务被 worker 永久遗漏。

## 数据权限与性能

- 页面字段是服务端 registry 白名单 key，不是 SQL 列名。
- 领域 provider 必须先按当前账号注入数据权限，再计算自定义字段；客户端范围只能缩小。
- 会员列表稳定分页使用隐藏正整数 member_id，不使用可能为空或重复的历史会员编号。
- 列表、分页、合计、分组和导出共用字段版本、查询截止日期和受控执行计划。
- 内存执行器最多处理 10,000 条已授权行；更大范围必须由领域 provider 将同一验证计划下推到事实或聚合 QueryBuilder。
