# 回滚或应急说明｜20260728-004-unified-query-custom-fields

## 首选应急方式

先关闭统一查询自定义字段、字段改名、查询设置保存和新建导出入口，保留七张元数据表。MySQL DDL 会自动提交，本包不能宣称事务回滚；执行前必须完成目标库备份和恢复验证。

## 尚未产生任何元数据

只有同时满足下列全部条件，才属于可评估物理回滚的空态：

- 七张表均为 0 行；
- 所有相关 command、projection、worker 和下载入口均已关闭；
- 资源版本表中没有本功能新登记且仍被使用的资源；
- 目标库备份、执行记录和原结构快照完整。

满足空态后，仍由 Codex 针对已核对目标库另行生成一次性逆序 DROP SQL；本包不附可直接复制执行的 DROP，避免误删已产生的查询设置或导出记录。

## 已产生字段、设置、引用或导出任务

禁止 DROP、TRUNCATE、物理删除版本或重置版本号。应：

1. 停止新写入口和导出 worker 领取。
2. 允许已领取任务在租约内完成，或等待租约过期后标记失败；不得让两个 worker 同时完成同一任务。
3. 保留字段稳定 key、不可变版本、查询设置、引用和已生成文件记录。
4. 修复代码后使用新的升级键补丁；不得修改已在任一目标库执行过的 SQL。
5. 对账字段当前版本与版本表、别名集合版本、查询设置引用和导出任务状态。

## 故障处理

- 当前字段找不到对应版本：立即关闭字段写入口，按字段 key、命令回执和版本记录恢复；禁止伪造表达式。
- 引用字段被停用或权限收回：将引用标为失效并阻断 pending 导出；保存查询和报表保留，提示移除、替换或恢复。
- 导出任务卡在 running：仅在 lease_expires_at 过期后允许新 worker 领取，旧 lease token 不得完成任务。
- 文件对象键异常：拒绝下载并标记任务失败；只允许运行时导出目录下的 xlsx 对象键。
- 结构签名不一致：停止发布，不使用 CREATE IF NOT EXISTS 掩盖漂移，另建修复升级。

## 不可执行操作

- 不物理删除有引用的字段。
- 不覆盖历史字段版本或历史导出表头。
- 不把任意 SQL、JS、PHP 或 Excel 公式写入查询计划。
- 不通过修改汇总数字“修复”查询结果。
- 不在未备份、未核对目标库时执行 DROP、TRUNCATE 或结构变更。
