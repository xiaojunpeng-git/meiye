# C2 entitlement completion dependency providers

- Upgrade key: `20260729-003-c2-entitlement-provider-dependencies`
- MySQL baseline: `5.6.51`
- Scope: four eventless technical metadata tables used before C2 entitlement-completion Gateway activation.

## Authority and data boundary

- `store_order` remains the origin-order authority. The debt guard only gives every `tenant + origin_order_id` a stable lock identity even when no debt row exists.
- `system_store_staff` plus its bound `employee` remain the staff identity and tenure authority. The staff profile version table only tracks an authority fingerprint and a positive concurrency version.
- `store_reservation_order` remains the current reservation occupation authority. The occupation version table only tracks an authority fingerprint and a positive concurrency version.
- No table in this package is a sales, payment, debt, writeoff, service, performance, inventory, event, Outbox, or reporting fact.

## Execution order

1. Confirm `20260727-001-cashier-v3-command-idem` is registered and the four legacy authority tables satisfy `01-升级前检查.sql`.
2. Run `01-升级前检查.sql`; it must print `PRECHECK_OK`.
3. Run `02-正式升级.sql` twice.
4. Run `03-升级后验证.sql`; it must print `POSTCHECK_OK`.
5. If a previous interrupted DDL left one to three target tables, do not drop them. Run `05-部分创表恢复.sql`; only `PARTIAL_DDL_RECOVERY_READY` permits rerunning step 3.
6. Register the upgrade only after code and integration tests pass.

This package does not activate a Gateway action, integrate legacy debt writers, deploy, write a remote database, or authorize `commit`/`push`.
