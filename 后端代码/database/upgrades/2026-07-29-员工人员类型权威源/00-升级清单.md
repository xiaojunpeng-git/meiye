# 员工人员类型权威源升级清单

- 升级键：`20260729-005-employee-employment-type-authority`
- 目标：在 `eb_employee` 建立员工级三态人员类型权威源，并增加总部隐藏权限 `setting-staff-employment-type`。
- 类型：`internal`（内部员工）、`partner`（合作方）、`outsourced`（外包）。
- 未分类：`employment_type_code IS NULL` 且 `employment_type_version = 0`。
- 历史边界：本包只新增权威字段，所有既有员工保持未分类；不从旧任职分成或合作方标记推断、回填或覆盖人员类型。
- 人工分类：总部授权人员后续在员工管理中明确选择 `internal`、`partner` 或 `outsourced`；旧字段不能区分合作方与外包，禁止猜测。
- 权限：平台超级管理员可管理；其他平台账号须显式获得 `setting-staff-employment-type`；代理和门店端拒绝。
- 历史：不改旧 `staff_yeji`、订单、收款、核销或业绩事实，不把新类型反写到旧任职标记。

执行顺序：

1. 备份目标库并执行 `01-升级前检查.sql`。
2. 仅在输出 `PRECHECK_OK` 后执行 `02-正式升级.sql`。
3. 执行 `03-升级后验证.sql`，保存未分类统计；未分类员工在被明确设置类型前不得参与需要人员类型快照的 V3 业绩分配。
4. 验证通过后按真实 SHA、代码版本和执行人写入 `eb_database_upgrade_log`。
5. 若 DDL 或菜单写入中断，先执行 `05-部分升级恢复审计.sql`；只有输出 `PARTIAL_UPGRADE_RECOVERY_READY` 才可重跑正式升级。

本升级当前只在唯一源码正本内创建，未授权远程执行、部署或写入生产数据库。
