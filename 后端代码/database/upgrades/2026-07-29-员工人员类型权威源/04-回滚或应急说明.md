# 回滚或应急说明

该升级新增的是员工主档权威字段和隐藏权限，不改订单、收款、核销、业绩或历史快照。

应急原则：

1. 代码未激活前，可停止使用新人员类型入口；不得把旧 `is_fencheng` 或 `is_hezuofang` 自动转换成合作方/外包。
2. 若 DDL 或菜单写入中断，先运行 `05-部分升级恢复审计.sql`。仅在输出 `PARTIAL_UPGRADE_RECOVERY_READY` 时重跑 `02-正式升级.sql`。
3. 若发现字段结构、菜单父级或已有数据不符合合同，停止自动恢复，备份后人工评估；不得删除有值字段。
4. 已发生人员类型保存后，不建议删列回滚。应保留字段和 `employee_change_log` 审计，停用入口并修复代码。
5. 只有在确认从未写入非空类型、没有任何 C2 快照或业务引用，且完成备份与零引用扫描后，才可另立回滚任务删除权限节点和两列；本文件不授权直接删除。
6. 数据库升级登记必须在验证通过后写入，失败或部分状态不得伪造成功记录。

本升级不包含部署、远程数据库操作、commit 或 push 授权。
