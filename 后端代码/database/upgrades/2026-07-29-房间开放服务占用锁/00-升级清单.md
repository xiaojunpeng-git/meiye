# 房间开放服务占用锁升级清单

- 升级键：`20260729-019-room-open-service-guard`
- 兼容基线：MySQL 5.6.51，表前缀 `eb_`。
- 新增 `eb_cashier_v3_room_open_service_guard`：一个租户、门店、房间只有一个 `open-service:<roomId>` 开放服务占用槽。
- 本迁移不扫描、不回填、不改写旧预约数据，也不激活任何 Gateway 入口。
- 写入方必须在外层业务事务中按“房间行 -> 占用 guard”加锁，占用或释放失败随主业务整体回滚。
- 执行顺序：`01-升级前检查.sql` -> `02-正式升级.sql` -> `03-升级后验证.sql` -> 逐实例登记。

当前仅本地开发，未指定任何客户实例，不授权远程写库、部署、`commit` 或 `push`。
