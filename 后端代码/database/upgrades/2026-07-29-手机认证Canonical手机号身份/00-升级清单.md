# MOBILE-AUTH Canonical 手机号身份升级清单

- 升级键：`20260729-013-mobile-auth-canonical-identity`
- 范围：仅建立 `eb_user_phone_identity` 及追加审计表；后续手机验证码、App/商家会话和员工手机号绑定属于独立 MOBILE-AUTH 结构升级。
- 权威源：身份映射由 `eb_user_phone_identity` 的 `BOUND` 行确定；`eb_user` 仍是会员经营主体与历史事实主键。
- 历史策略：不更新、不删除、不合并任何 `eb_user` 历史记录。唯一有效手机号回填为 `BOUND`；历史重复手机号只登记 `LEGACY_CONFLICT` 并 fail-closed；已注销的唯一手机号登记为 `RELEASED`。
- 锁序：身份映射先于会员主行。新旧收银 V3 手机号锁不在本升级中变更。
- 数据与发布：本包只在唯一源码正本中创建，未执行任何本地或远程数据库操作，未部署、未提交、未推送。

## 执行顺序

1. 在被产品经理点名的单一实例，先执行 `01-升级前检查.sql`；任一依赖键、表结构、重复升级或历史数据条件不满足即停止。
2. 备份该实例数据库后执行 `02-正式升级.sql`，随后立即执行 `03-升级后验证.sql`。
3. 中断时先执行 `05-部分创表恢复审计.sql`，确认无业务写入且可以恢复后才处理，不得手工删表或修改已执行 SQL。
4. 代码、扫描门禁和独立验收通过后，按实例登记真实 SQL SHA、结果和证据；未点名实例保持原状。
