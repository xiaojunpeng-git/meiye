# MOBILE-AUTH Canonical 身份升级应急说明

本升级会建立身份映射并回填新增表，但不改写 `eb_user`、订单、权益、余额、卡项、积分或员工资料。已执行的正式 SQL 不允许修改或通过删表回滚。

若 `02` 中断，先执行 `05-部分创表恢复审计.sql`。只有目标表为空、升级日志未登记、且 `05` 明确给出 `PARTIAL_DDL_RECOVERY_READY` 时，才允许在独立处置任务中恢复空的部分结构。存在任何映射或审计行时，保持原状并按新 `upgrade_key` 提供可审计修补；不得手工删除身份记录。

上线后若业务入口异常，先关闭尚未激活的新入口，保留映射表和审计记录，使用旧已发布功能维持服务。不得以绕过 Canonical 的方式恢复手机号写入。
