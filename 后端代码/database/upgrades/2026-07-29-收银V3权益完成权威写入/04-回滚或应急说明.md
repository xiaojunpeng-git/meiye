# 回滚与应急说明

三张新增表保存权益完成回执、核销事实和服务事实，统一业绩表同时保存对应消耗／劳动业绩。任何表已有数据后，禁止自动 `DROP`、截断或物理删除。

1. 升级前检查失败时立即停止，核对升级登记、先决迁移和目标表状态。
2. 部分创表时执行只读 `05-部分创表恢复.sql`。只有现存目标表结构签名正确且全部为空，才允许重新执行 `02` 补齐。
3. 任一目标表有数据、结构不一致或与统一业绩表无法对账时，保留现场并人工审计，不得覆盖唯一源码正本。
4. writer 抛出异常时必须由 Gateway 外层事务回滚；禁止捕获后继续提交 `processing` 回执或部分事实。
5. 已投入使用后的功能停用只能关闭新入口并保留事实。冲销必须新增反向事实和权益恢复事务，不允许改写历史行。
6. 本迁移不部署任何客户实例；后续必须逐实例核对 commit、迁移版本、备份、共享依赖和回滚点。
