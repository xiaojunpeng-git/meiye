# 回滚或应急说明

本包尚不激活 Gateway action，也不迁移历史数据。正常发布失败时优先回滚应用版本，并保留来源引用表供审计。

禁止直接在生产库执行无条件 `DROP TABLE`。只有同时满足以下条件，才可在独立维护窗口人工删除：

1. 该包从未被任何已上线代码写入或读取；
2. `eb_cashier_v3_checkout_source_reference` 行数为 `0`；
3. 升级登记尚未标记成功，或登记已按发布流程撤销；
4. 已保存建表 SQL、表结构和操作证据；
5. 已确认不存在并行部署或在途事务。

若表内已有数据，不删除、不改写。先停用尚未激活的接入点，核对每条 `request_id` 的 tenant/store、当前 `request_version` 和来源集合，再以新的升级键修复。

本表只是当前结账请求的技术来源绑定，不是经营事实；删除它不会冲销业务，反而会使后续结账来源无法权威反推，因此不能把删表当作业务回滚。
