# 收银 V3 统一结账事实底座升级清单

- 升级键：`20260729-007-cashier-v3-checkout-facts-v1`
- 合同：`cashier-v3-checkout-fact-plan-v1`
- 目标：建立销售、七类成功记账收款、余额变更、业绩结果四类不可变事实。
- 金额：全部使用 `bigint` 整数分；禁止浮点金额。
- 收款方式：仅 `unionpay`、`wechat`、`alipay`、`dianping_voucher`、`douyin_voucher`、`partner_collection`、`other_collection`。
- 明确拒绝：`old_card_entry` 不是收款事实，现金业绩为零，不能写入收款事实表。
- 业绩类型：`sales_performance_allocated`、`actual_performance_recorded`、`consumption_performance_recorded`、`labor_performance_allocated`。
- 历史：事实不可更新；退款、作废和调整写负数冲销事实并保存 `reversal_of`。
- 权限：写入仓储必须在调用方事务内，并使用服务端 `CashierV3DataScopeContext` 强制租户、组织、门店和操作人范围。
- 激活：本包不修改 Bootstrap、Gateway、manifest、路由或前端，不激活任何 action。

执行顺序：

1. 备份目标库并执行 `01-升级前检查.sql`。
2. 仅在输出 `PRECHECK_OK` 后执行 `02-正式升级.sql`。
3. 执行 `03-升级后验证.sql`。
4. 验证通过后，按真实文件 SHA、固定代码版本和执行人登记升级日志。
5. 若多表 DDL 中途失败，先执行 `05-部分创表恢复.sql`；只有输出 `PARTIAL_CREATE_RECOVERY_READY` 才可重跑 `02-正式升级.sql`。

本升级未授权远程执行、部署、历史回填、commit 或 push。
