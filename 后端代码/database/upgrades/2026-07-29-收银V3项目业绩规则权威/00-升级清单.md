# 收银 V3 项目业绩规则权威

- upgrade_key: `20260729-016-cashier-v3-project-performance-rule-v1`
- MySQL baseline: 5.6.51, InnoDB, `utf8mb4_general_ci`
- 一条记录对应一个租户下的一个项目，保存消耗业绩与劳动业绩的计算方式和正版本。
- 未配置项目在首次进入最终锁定时创建版本 1，默认两类业绩均按本次权益实际金额计算。
- 该表是 eventless 技术配置权威，不是业绩事实；结账只读取并固结规则，不得因消费而推进规则版本。
- 后续配置写入必须由专用权威入口在锁行后更新口径并将版本严格 `+1`；不得借用结账 Gateway 的 touched 推进。
- 结账事实保存发生时规则版本和金额，后续规则变化不反改历史。
- 执行顺序：`01-升级前检查.sql` -> `02-正式升级.sql` -> `03-升级后验证.sql` -> 登记升级键。前检失败时不得继续。
- 若目标表曾被手工或异常流程提前创建，先执行只读 `05-部分创表恢复.sql`；只有结构精确、未登记且空表才允许重跑正式升级。
- 本升级只建立本地源码正本；未授权在任何客户实例执行。
