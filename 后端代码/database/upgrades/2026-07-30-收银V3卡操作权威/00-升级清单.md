# 收银 V3 卡操作权威升级清单

- 升级键：`20260730-021-cashier-v3-card-operation-authority-v1`
- 数据库兼容基线：MySQL 5.6.51；表前缀 `eb_`。
- 新增卡当前状态投影、不可变卡操作主记录和操作明细三张表。
- 前置依赖已安装的 V3 命令回执、业务事件、Outbox 与权益版本表；缺任一项必须停止升级，不能只落卡操作表。
- 卡转让只变更 V3 权益当前持有人，不改写原销售订单的历史会员归属。
- 卡延期、停用、启用以状态投影生效；每次变更都保留发生时快照、操作人、原因、版本和幂等键。
- 项目替换、项目升级与卡升级在正式命令接入后写同一操作审计；涉及补价时必须绑定成功结账，不能先改权益后收款。
- 执行顺序：`01-升级前检查.sql`、`02-正式升级.sql`、`03-升级后验证.sql`；部分创表或未登记全量创表只运行 `05-部分创表恢复审计.sql`，不得直接补跑正式 SQL。
- 本包的本地兼容证据由 `06-本地MySQL56矩阵.sh` 生成；它覆盖全新安装、重复执行、唯一键、CAS、结构篡改、部分创表和未登记全量创表的 fail-closed 门禁。
- 本目录只定义统一源码迁移；未授权远程部署或对其他客户实例执行。
