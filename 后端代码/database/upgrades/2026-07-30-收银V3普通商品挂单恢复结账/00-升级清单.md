# 收银 V3 普通商品挂单恢复结账升级清单

- 升级键：`20260730-022-cashier-v3-sale-hang-resume-checkout-v1`
- MySQL 兼容基线：5.6.51；表前缀为 `eb_`。
- 在既有 V3 挂单、挂单明细和收银工作台草稿上新增恢复绑定、结账绑定和可信工作台行快照字段。
- 只支持本升级后新建的普通产品挂单恢复并正式结账。旧挂单、服务中挂单、项目/卡项挂单不迁移、不兼容，保持不可提取。
- 执行顺序：先运行 `01-升级前检查.sql`，再运行 `02-正式升级.sql`，最后运行 `03-升级后验证.sql`。
- 本包不写历史业务数据，不释放旧房间占用，不补建旧服务单；只改变后续新挂单的存储能力。
- 发生部分 DDL、非预期列或结构不一致时，只运行 `05-部分升级恢复审计.sql`，不得删除或手工修改挂单数据。
