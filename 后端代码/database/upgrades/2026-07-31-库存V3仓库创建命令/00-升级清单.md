# 库存 V3 仓库创建命令

- 升级 key：`20260731-004-inventory-v3-warehouse-create-command`
- 目标：为 `eb_inventory_location` 补充创建人审计字段，并登记平台仓库创建 API 权限节点。
- 业务边界：仓库是库存主数据。本升级不创建库存、批次、出入库事实、订单、会员、支付或服务事实。
- 命令规则：仅平台“仓库管理”权限可创建；后端从可信登录管理员和组织范围校验目标门店；新仓固定为 `STORE`、`ACTIVE`、非默认仓；请求以稳定仓库编码幂等，同门店同名称由服务端命名锁串行防重。
- 当前本地验证实例：`ruihao_test_20260731`。仅在本地验证通过后，由“瑞昊上线进程管理”逐实例登记和执行；不得手工插入仓库数据替代该命令。
- 依赖：已存在 `eb_inventory_location`、`eb_system_menus`、`eb_system_store`、`eb_organization_store` 与库存 V3 平台权限升级。
