# 回滚或应急说明

本升级只登记六条平台库存 V3 API 权限节点，不改业务事实、库存余额或历史单据。

若升级后、给任何角色授权前需要撤回，可在逐实例确认后删除 `unique_auth` 为以下三个值且 `api_url` 以 `product/inventory/v3/` 开头的六条节点：

- `inventory-v3-platform-batch-view`
- `inventory-v3-platform-batch-cost`
- `inventory-v3-platform-batch-export`
- `inventory-v3-platform-query-manage`

一旦角色规则或发布包已依赖这些节点，不得只删菜单记录；应先回退到与本升级匹配的上一个代码版本，再逐实例复核角色规则、缓存和访问日志。任何回滚均不得删除库存、订单、会员或导出事实。
