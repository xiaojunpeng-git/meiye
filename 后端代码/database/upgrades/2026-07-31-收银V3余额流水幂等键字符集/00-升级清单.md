# 收银 V3 余额流水幂等键字符集

- 升级键：`20260731-002-cashier-v3-balance-ledger-idempotency-ascii`
- 前置：旧余额流水表 `eb_user_money` 为 InnoDB，`idempotency_key` 为可空 `varchar(128)`，且非空值全为 ASCII、无重复。
- 变更：把已有 `idempotency_key` 统一为 `ascii` / `ascii_bin`。不新增、删除或修改任何余额流水金额、会员余额或幂等键内容。

## 目的

收银 V3 余额权威迁移要求幂等键按 ASCII 二进制比较，避免不同库默认排序规则造成重放判断漂移。瑞昊旧快照已存在同名 UTF-8 唯一键，原余额权威包会按“列存在”跳过它；本独立包先将旧列收敛到正确结构。

## 执行顺序

备份 → 校验 `SHA256SUMS.txt` → `01` → `02` → `03` → 成功登记真实 SQL SHA。若发现非 ASCII 或重复键，停止并保留证据，不能转换、删除或覆盖原值。
