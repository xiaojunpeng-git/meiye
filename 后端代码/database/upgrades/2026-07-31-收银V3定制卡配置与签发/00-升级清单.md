# 收银 V3 定制卡配置与签发

- 升级 key：`20260731-005-cashier-v3-custom-card-configuration`
- 目标：为定制卡新增门店范围的不可变配置主表。它只保存已选项目、次数、金额、有效期和开卡方式的冻结快照；成功结账后仍通过现有 V3 销售订单、收款事实和卡项权益签发链路落账。
- 数据边界：配置状态只允许 `in_cart`、`settled`、`cancelled`。配置不是销售事实、收款事实或权益；`settled` 由最终结账事务写入，禁止手工改写。
- 幂等：`tenant_id + created_command_idempotency_key` 与 `tenant_id + configuration_id` 均唯一；同一命令重试只回放同一配置。
- 本地验证实例：`ruihao_test_20260731`。执行、对账与后续逐实例上线由【瑞昊上线进程管理】登记，禁止直接手工插入测试数据替代命令。
- 依赖：已安装收银 V3 工作台、销售购物车、卡项权益签发、卡操作权威迁移。
