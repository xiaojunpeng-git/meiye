# 回滚或应急说明

本升级不改表结构，只为符合明确条件的历史员工写入人员类型及审计。

回滚前必须备份：

- `eb_employee` 中本次目标员工的完整行；
- `eb_employee_change_log` 中
  `action='employee_employment_type_default_internal'` 的全部行；
- `eb_database_upgrade_log` 中本 upgrade_key 的登记行。

仅在确认上线后尚未由平台人工修改人员类型时，才可按本次审计目标回滚：

```sql
START TRANSACTION;

UPDATE eb_employee employee
INNER JOIN eb_employee_change_log audit
  ON audit.employee_id=employee.id
  AND audit.action='employee_employment_type_default_internal'
SET employee.employment_type_code=NULL,
    employee.employment_type_version=0
WHERE employee.employment_type_code='internal'
  AND employee.employment_type_version=1;

DELETE FROM eb_employee_change_log
WHERE action='employee_employment_type_default_internal';

DELETE FROM eb_database_upgrade_log
WHERE upgrade_key='20260801-002-active-store-employee-default-internal';

COMMIT;
```

如果某员工已被人工改为其他类型或版本大于 1，禁止批量回滚该员工；应保留现状并逐人审计。
