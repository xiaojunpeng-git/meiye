# 库存 V3 默认门店仓基线

- 升级 key：`20260801-003-inventory-v3-default-store-location-baseline`
- 前置升级：`20260729-003-inventory-batch-query-facts`
- 目标：为有效、已绑定组织的门店补齐唯一的 ACTIVE 默认门店仓，恢复库存 V3 查询、入库和收银正式产品销售的共同库存边界。
- 业务边界：只创建缺失的库存地点主数据；不创建库存、批次、库存移动、订单、支付、会员权益或事实记录。
- 幂等：仅插入不存在默认仓的门店；使用稳定的 `STORE-<store_id>` 仓库编码；重复执行不重复创建。
- 安全：迁移先从组织树生成门店当前组织路径。缺少组织绑定、组织循环、同门店多默认仓或仓库编码冲突均会失败，禁止静默修补。
- 兼容基线：MySQL 5.6.51。

执行顺序：`01` 预检 → 备份预检结果 → `02` 升级 → `03` 后检 → 登记 SQL SHA256 与实例执行结果。
