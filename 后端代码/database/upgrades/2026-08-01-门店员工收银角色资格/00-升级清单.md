# 门店员工收银角色资格升级清单

- upgrade_key：`20260801-001-store-staff-cashier-role-eligibility`
- 目标：在门店任职 `eb_system_store_staff` 上建立“可作为销售人”和“可作为手艺人”两个独立权威开关。
- 默认口径：新建任职及全部既有任职默认两个开关均开启。
- 数据边界：开关只决定当前门店收银、预约、核销是否可选择该任职；不修改员工主档和历史业务事实。
- 人员类型边界：销售人仍须具有明确的 `internal/partner/outsourced` 人员类型，禁止由本升级静默推断或回填。
- 兼容基线：MySQL 5.6.51。

执行顺序：

1. 只读执行 `01-升级前检查.sql`。
2. 执行 `02-正式升级.sql`。
3. 只读执行 `03-升级后验证.sql`。
4. 登记 upgrade_key、执行实例和验证结果。
