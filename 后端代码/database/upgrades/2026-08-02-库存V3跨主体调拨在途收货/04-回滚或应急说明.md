# 跨主体调拨在途收货：回滚与应急

本升级只新增 V3 权威单据与关联表，不迁移、覆盖或删除旧调拨数据。

- 未创建单据：可关闭新入口并回退应用。
- `DRAFT`：可取消，不产生库存事实。
- `DISPATCHED`：源仓已经扣减，只能由目标主体收货；不允许作废、取消、撤回发货或直接改库存。异常先关闭写入口并保留现场，待收货完成后再由当前持货方按批次谱系新建反向调拨。
- `RECEIVED`：两侧已产生事实，不允许作废或取消；需要退回时由当前持货方按批次谱系新建反向调拨，不得物理删除单据、批次或事实。
- 任何数量、成本或请货履约对账异常，先关闭发货／收货写入口，保留现场与事实，再执行逐单核对。
