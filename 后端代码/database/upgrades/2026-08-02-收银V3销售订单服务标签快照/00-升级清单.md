# 收银 V3 销售订单服务标签快照

- 升级键：`20260802-001-cashier-v3-sales-order-service-tags-v1`
- 兼容基线：MySQL 5.6.51 / InnoDB / `utf8mb4_general_ci`。
- 依赖：已执行收银 V3 正式销售订单权威、结账草稿及服务设置迁移。

## 变更

为 `eb_cashier_v3_sales_order_line` 新增不可变的 `service_object` 与
`is_experience` 快照列。新结账的项目行从已锁定结账草稿复制“本人／朋友”和
“体验”标记；产品与卡项固定为空对象、非体验。订单详情只读取这些订单行快照。

不回填、不更新或删除任何已结账历史订单。历史行使用数据库默认值（空对象、非体验）。

## 执行顺序

1. 对目标实例核对固定 commit、迁移记录、备份和回滚点。
2. 校验 `SHA256SUMS.txt`，执行 `01-升级前检查.sql`；仅 `PRECHECK_OK` 可继续。
3. 执行 `02-正式升级.sql`、`03-升级后验证.sql`；仅 `POSTCHECK_OK` 可登记。
4. 按统一升级流程登记完整 SQL SHA 后重跑 `03-升级后验证.sql`。
5. 新建一笔项目销售订单，核对确认页和订单详情均显示体验／本人或朋友标签。

本包不授权远程写库、部署、历史回填、提交或 push。
