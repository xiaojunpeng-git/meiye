# 库存 V3 Excel 导入

- Upgrade key: `20260803-002-inventory-v3-excel-import`
- Dependency: `20260803-001-inventory-v3-business-document-numbers` 已成功登记；V3 批次入库、出库和业务单号映射已可用。
- Scope: 新增 V3 专属导入记录与错误行表。它们只记录新导入文件的证据、幂等和结果，不复用旧库存导入的记录、文件哈希或台账写入。
- Write authority: 入库最终调用 `InventoryManualInboundServices::createForImport`，出库最终调用 `InventoryManualOutboundServices::createForImport`；二者仍在同一业务事务内写 V3 批次余额和不可变事实。
- Idempotency: 同一租户、门店、方向和文件哈希成功后永久拒绝重导；失败记录允许修表后重试，旧失败错误行会被新一次尝试替换。
- Data rule: 残次品数量必须为 `0`，非零整行失败；同一文件必须为同一业务日期和业务类型，成功时形成一张新 `RK` 或 `CK` 单据。
- Historic compatibility: 不回填、不清理、不修改旧库存、旧导入记录、历史批次或事实。
- Execution: 核对 `SHA256SUMS.txt` 后依序执行 `01-升级前检查.sql`、`02-正式升级.sql`、`03-升级后验证.sql`。仅 PRECHECK 与 VERIFY 通过后，才可由受控发布流程登记升级日志。
- Rollback: 未产生记录时可删除两张新表；已有导入记录或已生成业务事实时不得删除数据，回滚代码应仅停止新入口。
