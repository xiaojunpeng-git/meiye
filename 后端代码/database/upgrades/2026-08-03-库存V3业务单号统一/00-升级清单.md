# 库存 V3 业务单号统一

- Upgrade key: `20260803-001-inventory-v3-business-document-numbers`
- Dependency: `20260802-003-inventory-v3-cross-subject-transfer-receipt` 已成功登记；库存 V3 批次事实、手工入/出库、盘点、请货和院装表均存在。
- Scope: 仅为升级后新创建的库存业务分配用户可见单号。既有库存单据、批次、事实、余额和技术幂等键均不回填、不清理、不修改。
- Number rule: `功能缩写 + YYMMDD + 当日四位流水`。入库 `RK`、出库 `CK`、盘点 `PD`、请货 `QH`、调拨 `DB`、院装领用 `YZLY`、院装退回 `YZTH`；例：`RK2608030001`。
- Authority: 业务单据主表仍为权威源，手工入/出库没有单头时使用只追加的单号映射表。技术幂等键继续用于重放，不替代业务单号。
- Transaction: 序号分配、业务写入与事实写入在同一事务内；失败回滚不留映射。重试复用已有单据或映射，不占新号。
- Execution: 核对 `SHA256SUMS.txt` 后依序执行 `01-升级前检查.sql`、`02-正式升级.sql`、`03-升级后验证.sql`。仅当 PRECHECK 与 VERIFY 均通过，才由受控发布流程登记升级日志。
- Rollback: 未产生新单据时可删除两张新表；一旦已产生新业务单号，不删除数据，回滚代码应继续读取映射并停止发放新号。
