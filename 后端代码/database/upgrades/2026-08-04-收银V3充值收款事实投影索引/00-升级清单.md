# 收银 V3 充值收款事实投影索引

- `upgrade_key`: `20260804-005-cashier-v3-recharge-payment-fact-read-index`
- 兼容基线：MySQL 5.6 / InnoDB / `utf8mb4_general_ci`。
- 依赖：`eb_cashier_v3_payment_fact` 已由收银 V3 统一结账事实底座创建。

## 变更

新增 `idx_recharge_projection (source_document_type,status,store_id,order_no_snapshot)`。

订单中心的充值页只按有效 V3 收款事实读取现金业绩，查询条件固定为充值来源、有效状态、门店和充值单号。本索引覆盖该过滤和分组前缀，避免随着事实表增长退化为全表扫描。

不回填、不截断、不更新和不删除任何既有数据。

## 执行顺序

1. 在被明确点名的实例执行 `01-升级前检查.sql`，仅 `PRECHECK_OK` 可继续。
2. 执行 `02-正式升级.sql`，再执行 `03-升级后验证.sql`，仅 `POSTCHECK_OK` 可登记。
3. 核对 `SHA256SUMS.txt` 后登记 `eb_database_upgrade_log`。

本包不授权远程写库、部署、提交或 push。
