# 收银 V3 销售订单手艺人快照应急说明

本包只新增两列，不改写任何业务数据或事实。

如升级中断或 `03-升级后验证.sql` 未通过，停止该实例继续进行收银结账验收，先
只读确认两个目标表的列状态与升级登记状态。不得通过更新旧订单、草稿或员工资料
来补充快照。

若两列均已创建但尚未有新版本结账写入，可在单独处置任务、明确确认无新快照数据
后执行：

```sql
ALTER TABLE `eb_cashier_v3_checkout_line_draft`
  DROP COLUMN `craftsmen_snapshot_json`;
ALTER TABLE `eb_cashier_v3_sales_order_line`
  DROP COLUMN `craftsmen_snapshot_json`;
```

一旦存在新结账或新销售订单快照，不得通过删列回滚；这会抹掉发生时手艺人历史。
应保留列、停止对应应用版本并通过后续受控修复恢复读取链路。
