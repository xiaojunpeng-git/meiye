# 员工类型全量内部归类与手机端权限目录升级清单

- 升级键：`20260805-002-employee-type-mobile-catalog-normalization`
- 目标：收口尚未分类的在职员工人员类型，并将每个未删除岗位的手机端规则统一为当前 Vue 3 商家端完整功能目录。
- 兼容基线：MySQL 5.6.51。

## 本次口径

1. 仅更新 `status=1 AND is_del=0 AND employment_type_code IS NULL AND employment_type_version=0` 的员工：设置为 `internal / 1`，并写入一条迁移审计。
2. 旧门店任职中的 `is_hezuofang`、`is_fencheng` 不再阻止本次归类；它们不是员工主档的人员类型权威源。
3. 已明确为 `partner` 或 `outsourced` 的员工，以及任何已有非零类型版本的员工，绝不覆盖。
4. 每个未删除岗位设置 `use_mobile=1`，并在 `eb_job_position_channel_rule` 中写入 `channel='mobile'`、`status=1` 与完整目录规则：
   `401100,401001,401002,401003,401004,401005,401006,401007,401008,401200,401300`。
5. 本包不修改 `staff_channel_entry`、`employee_mobile_auth`、`employee_mobile_auth_state` 或任一员工的手机端个人启用/停用状态。

## 执行顺序

1. 在目标实例完成备份后，只读执行 `01-升级前检查.sql`。
2. 仅在输出 `PRECHECK_OK` 后执行 `02-正式升级.sql`；正式脚本可重放，不会重复改写已完成员工或无变化岗位规则。
3. 只读执行 `03-升级后验证.sql`，保存人员类型、岗位规则与审计统计。
4. 验证通过后，以本包 `SHA256SUMS.txt` 中的真实 SHA、目标实例、代码版本与执行人登记 `eb_database_upgrade_log`。

本包只创建于统一源码正本，未授权执行本地或远程数据库、部署、commit 或 push。
