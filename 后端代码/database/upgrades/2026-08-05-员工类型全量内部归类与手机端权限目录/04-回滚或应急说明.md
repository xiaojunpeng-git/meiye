# 回滚或应急说明

本包会写入员工主档人员类型、迁移审计、岗位 `use_mobile` 和岗位手机端规则。它不会改写任何员工个人手机端启用／停用投影。

应急处置：

1. 若 `01-升级前检查.sql` 或 `03-升级后验证.sql` 未通过，停止登记升级键，不要手工补写员工或岗位规则。
2. 若正式脚本中断，先重新执行 `01-升级前检查.sql`；只有 `PRECHECK_OK` 时才可重跑 `02-正式升级.sql`。条件更新与唯一岗位渠道键保证可重放。
3. 不提供自动批量回滚 SQL：员工可能已在升级后被平台人工改为合作方／外包，岗位也可能被管理员调整。不得删除迁移审计、清空人员类型或盲目恢复旧岗位规则。
4. 必须回退时，先从升级前备份和本包审计定位受影响对象；仅对尚未发生后续人工修改的单条员工、单个岗位建立新的受控纠正升级，保留原审计和升级登记。
5. 本文件不授权修改 `eb_staff_channel_entry`、`eb_employee_mobile_auth`、`eb_employee_mobile_auth_state`、远程数据库、部署、commit 或 push。
