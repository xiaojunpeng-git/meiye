# 收银 V3 订单生命周期权威

- 升级键：`20260805-004-cashier-v3-order-lifecycle-authority`
- 数据库兼容：MySQL 5.6
- 范围：新增 V3 销售订单操作、重开草稿、资金冲销、欠款取消和卡权益撤销权威表。
- 不回填、不处理旧订单；只在新 V3 销售订单的正式退款/作废事务中冲销余额、未还欠款和可证明完全未使用的卡权益；库存仍失败关闭。
- 执行前必须完成 V3 销售订单和统一结账事实升级。
- 固定执行顺序：`01-升级前检查.sql` → `02-正式升级.sql` → `03-升级后验证.sql`。
- `PRECHECK_OK` 和 `POSTCHECK_OK` 均为必需门禁；出现 `STOP_` 立即停止。
- 回滚边界见 `04-回滚或应急说明.md`。
