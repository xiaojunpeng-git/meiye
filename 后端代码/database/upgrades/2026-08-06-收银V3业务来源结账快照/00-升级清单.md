# 收银 V3 业务来源结账快照

- 升级键：`20260806-003-cashier-v3-checkout-business-source-snapshot`
- 依赖：`20260806-002-cashier-v3-business-source-accounting-config`。
- 目标：把销售、充值结账中的业务来源作为独立、可并发校验的草稿选择，并在成功订单上保存来源 ID 与发生时名称快照。

- 顺序：`01-升级前检查.sql` → `02-正式升级.sql` → `03-升级后验证.sql`。
