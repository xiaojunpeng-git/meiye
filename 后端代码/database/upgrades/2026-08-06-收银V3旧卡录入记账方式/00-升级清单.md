# 收银 V3 旧卡录入记账方式

- 升级键：`20260806-004-cashier-v3-old-card-entry-accounting-method`
- 目标：在平台“记账设置”中补齐稳定代码 `old_card_entry`，默认显示名称为“旧卡录入”，用于历史会员卡、权益和余额遗漏导入后的独立录入流程。
- 依赖：`20260806-002-cashier-v3-business-source-accounting-config` 已建立记账方式配置表；`20260806-003-cashier-v3-business-config-platform-menu` 已提供平台入口。
- 业务边界：旧卡录入不是记账收款，不可与正常收款组合；不生成收款事实、现金业绩、销售业绩、劳动业绩或实际业绩。
- 幂等：以稳定代码 `old_card_entry` 写入；重复执行仅校正默认名称，不覆盖已配置的显示名称、启停状态或排序。
- 回滚：紧急时在平台将该方式停用；禁止删除历史权益、订单、事实或配置审计。
