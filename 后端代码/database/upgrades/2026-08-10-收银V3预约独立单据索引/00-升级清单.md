# 收银 V3 预约独立单据索引

- `upgrade_key`: `20260810-005-cashier-v3-reservation-independent-document-index-v1`
- 兼容基线：MySQL 5.6 / InnoDB / `utf8mb4_general_ci`。
- 前置：`20260730-001-cashier-v3-reservation-authority` 和
  `20260810-004-cashier-v3-reservation-entitlement-source-v1` 已在目标实例登记。

## 变更

预约不再创建或关联服务单，`service_order_id` 固定为 `0`。原表的唯一索引
`uk_tenant_service_order (tenant_id, service_order_id)` 会导致同一租户只能保存
一张独立预约，因此本包移除该唯一索引并新增同字段的普通查询索引
`idx_tenant_service_order`。

不回填、不修改、不删除旧预约数据；保留 `service_order_id` 字段只用于旧数据
读取兼容，预约新流程不再依赖它。

## 执行顺序

1. 仅在产品经理点名的独立实例，只读执行 `01-升级前检查.sql`。
2. 仅预检结果可继续时，执行 `02-正式升级.sql`。
3. 只读执行 `03-升级后验证.sql`，确认唯一索引已移除、普通索引存在且 `APPLY_OK`。
4. 核对 `SHA256SUMS.txt`，登记升级键、实例、执行人、执行时间和验证输出。

本包不授权远程写库、部署、提交或 push。
