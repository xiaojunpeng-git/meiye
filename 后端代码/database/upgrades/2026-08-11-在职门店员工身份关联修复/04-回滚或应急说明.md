# 回滚或应急说明｜20260811-003-active-store-staff-employee-identity-repair

仅当客情功能尚未上线、这些新员工身份尚未被后续人员配置或业务记录引用时，才可回滚。

1. 先备份 `eb_employee`、`eb_system_store_staff`、`eb_employee_change_log` 和升级日志。
2. 根据 `eb_employee_change_log` 中 `action='employee_identity_repaired_from_staff'`、本升级键的 `before_data` 恢复每个任职原 `employee_id`。不得根据名称推断。
3. 新建员工主档不物理删除；置为离职/删除并保留审计，避免 ID 被复用。
4. 删除该升级日志后重新执行 `03-升级后验证.sql`，确认回滚状态；如果已产生后续授权、手机认证、客情或其他业务引用，停止回滚并从备份恢复到隔离库评估。

本迁移不改业务事实，因此不允许通过修改订单、业绩、会员或客情历史来“对齐”回滚结果。
