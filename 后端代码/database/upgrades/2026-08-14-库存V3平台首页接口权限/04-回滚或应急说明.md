# 回滚或应急说明

本升级只新增平台库存 V3 首页概览的 API 权限节点，不修改库存业务数据。

若升级后需要回退，应先确认没有依赖该接口的正在进行的验收，再按实例执行：

```sql
DELETE FROM `eb_system_menus`
WHERE `type`=1
  AND `is_del`=0
  AND `api_url`='product/inventory/v3/dashboard'
  AND `methods`='GET'
  AND `unique_auth`='inventory-v3-platform-batch-view';
```

回退后重新清理 `system_menus` 权限缓存，并重新登录平台账号。不得删除或回滚库存数量、批次、金额及业务事实。
