# 收银 V3 收款方式按销售明细分摊事实

- upgrade_key: `20260815-004-cashier-v3-payment-sale-allocation-fact`
- 作用：成功结账时按销售明细冻结每笔记账收款方式的分摊金额，会员消费明细不再把订单付款总额重复显示在每一行。
- 分摊：每种收款方式独立按“销售成交金额减去该销售明细已记欠款”分摊；分为单位按最大余数补齐，保证每种方式的金额守恒。
- 历史订单不回填。退款、作废等反向事实写负数分摊并关联原分摊事实。
- 执行顺序：`01-升级前检查.sql` -> `02-正式升级.sql` -> `03-升级后验证.sql`。
- MySQL 5.6 兼容、可重复执行、只新增表，不覆盖已有事实。
