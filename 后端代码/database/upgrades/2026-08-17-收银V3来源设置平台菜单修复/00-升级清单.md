# 收银 V3 来源设置平台菜单修复

- 升级键：`20260817-002-cashier-v3-business-config-platform-menu-repair`
- 依赖：`20260806-002-cashier-v3-business-source-accounting-config`、`20260806-003-cashier-v3-business-config-platform-menu`。
- 目标：修复“来源设置”“记账设置”的平台菜单投影，使两项都位于“商品设置”下，并使用正确的页面路由与菜单路径；为已有商品设置权限的有效岗位补齐两个页面及既有来源/记账配置接口权限。
- 数据边界：仅修改 `eb_system_menus` 的菜单投影和 `eb_system_role.rules` 的权限引用；不修改来源配置、记账方式、结账选择、订单、审计或历史快照。
- 幂等：按稳定 `unique_auth`、父菜单标识和接口权限标识修复，可安全重复执行。
- 回滚：紧急情况下仅隐藏两个页面菜单或移除相应岗位权限引用；禁止删除来源配置、审计记录或历史订单快照。
