# 收银 V3 服务记录作废

| 项目 | 内容 |
|---|---|
| 目的 | 支持服务记录填写原因后作废，返还对应权益次数，并以反向事实冲销消耗业绩、手艺人劳动业绩和手工费 |
| 新表 | `eb_cashier_v3_service_record_void_operation`、`eb_cashier_v3_entitlement_reversal_fact` |
| 原事实 | `eb_cashier_v3_entitlement_service_fact`、`eb_cashier_v3_entitlement_writeoff_fact`、`eb_cashier_v3_performance_fact` 只读，不删除、不覆盖 |
| 幂等 | 同一租户同一 `service_fact_id` 只能有一条成功作废操作；命令键另有唯一约束 |
| 时间 | `occurred_at`、`settled_at`、`recorded_at` 全部由服务端写入，前端不可传入 |
| 回滚 | 见 `04-回滚或应急说明.md`。业务表不做物理回滚，异常通过追加事实冲销或恢复备份处理 |
