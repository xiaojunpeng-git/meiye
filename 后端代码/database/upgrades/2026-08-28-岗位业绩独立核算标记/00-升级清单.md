# 岗位业绩独立核算标记

- 升级键：`20260828-002-job-position-performance-independent`
- 目标表：`eb_position`
- 变更：新增 `performance_independent`，`tinyint unsigned NOT NULL DEFAULT 0`。
- 业务含义：岗位开启后，收银将其人员作为独立分配组；独立岗位组与普通岗位组均可各自按 100% 分配。销售业绩、手工费和项目数按各分配组分别记录，因此订单人员业绩合计可高于订单金额。
- 边界：该字段不改变岗位权限、数据范围或历史订单快照；已有订单仍按下单时快照读取。
- 兼容：历史岗位默认 `0`（不独立），可重复执行。
- 执行顺序：01 升级前检查 → 02 正式升级 → 03 升级后验证。
- 远程实例：瑞昊服务器上的 `ruihao`、`xinruihao`；已按实例分别完成备份、正式升级与后检，执行证据登记在数据库升级总表。
