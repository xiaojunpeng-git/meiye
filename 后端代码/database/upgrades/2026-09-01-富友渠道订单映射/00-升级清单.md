# 富友渠道订单映射

- upgrade_key: `20260901-001-fuyou-payment-attempt`
- 作用：保存富友20位数字渠道单号与本地业务单号的映射，供异步回调准确、幂等地还原业务订单；补齐普通浏览器微信支付生成小程序 URL Link 所需的访问令牌缓存表。
- 权威业务事实仍为订单、充值单、会员单和欠款补交单；本表仅记录支付渠道尝试，不作为营业收入或支付成功事实。
- `eb_wechat_accesstoken` 仅缓存微信访问令牌，不保存订单或收款事实。
- 执行顺序：`01-升级前检查.sql` -> `02-正式升级.sql` -> `03-升级后验证.sql`。
- MySQL 5.6 兼容、可重复执行、只新增表。
