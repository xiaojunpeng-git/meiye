# 共享导出来源隔离发布屏障

本文件不是执行迁移、停止服务或上线授权。04 SQL 未执行，不得与新建 AI 空表迁移一起自动运行。

1. 按实例记录源码/迁移指纹、旧表结构和备份、所有报表导出创建入口、队列消费者、定时 CLI、指定 taskNo 执行入口和恢复入口。AI Excel 保持关闭，试运行也不得提前创建 AI 行。
2. 阻断新的普通报表导出创建及重试。业务影响：维护窗口内门店和总部暂不能新建报表 Excel，已完成文件仍按原权限访问。明确通知窗口与回滚点。
3. 停止并核实全部旧导出消费者已物理退出；不能用 240 秒时限、300 秒租约或代码文件替换推定已退出。Swoole 依既有单实例规则核实后才平滑 reload，禁止重复启动多实例；驻留代码与队列消费者分别核实。
4. 在没有 AI 行且创建阻断的窗口内完成增列、REPORT 回填、NOT NULL 收紧全部三步。既不保留数据库默认 REPORT，也不保留应用缺省 REPORT。失败不恢复创建，先按备份/兼容版本处理。
5. 部署来源守卫兼容版本，覆盖扫描、指定 taskNo、claim、续期、完成、恢复、清理。先恢复普通报表创建并回归 query/page；普通队列名保持不变。源类型只接受 REPORT/AI，执行分区只由来源派生。
6. 部署 AI_EXPORT 独立消费者及保留执行容量，防止旧守护脚本/定时命令复活。验证所有存活消费者最低版本、当前权限重读、关闭即取消、原 deadline、24 小时清理、文件与原证据一致，再按端登记启用。进程分开不等于资源容量已实测；缺少证据不得启用。

回滚默认目标为“AI 关闭、普通可用、来源守卫保留”的兼容版本。完整回退前必须清理全部 AI 行与相关运行文件并证实 AI Worker 全部退出，禁止把不识别来源的旧 Worker 放回含 AI 行的共享表。备份恢复后默认关闭 AI 创建。

普通未迁移数据库仅允许原 REPORT 路径；部分 schema 或空 source_type 不得被当作历史普通行。04 迁移必须逐实例另行授权执行。

## 专用消费者与保留治理

AI 文件队列真实名称由 `AiExportQueue::name(AiRuntimeFactory::make()['instance'])` 获取，格式为 `MOHE_PRO_AI_EXPORT:<当前可信实例指纹的 SHA-256 前32位>`，不得只监听无实例后缀的名称。发布清单应登记实际完整名称、专用 Worker 数与物理文件保留槽；普通报表默认队列保持不动。通过现有 ThinkPHP `queue:work --queue <完整名称>` 启动专用消费者，必须先核对已授权实例和全部来源守卫屏障；此处命令说明不是启动授权。

`mohe_ai.export.monitoring_ready` 默认为 false，并参与真实能力就绪判断。只有登记实例容量/导出失败告警阈值、验证监控告警与清理失效检测后才可开启；当前管理员分类计数不等于告警链路，不能据此置 true。隔离自动化中的 true 仅为测试组合，不是任何客户实例的放行证据。

AI 投递只调用 Think Redis connector 一次，不经通用自动重试或载荷日志包装。无法确认投递结果记为 UNKNOWN，不自动重发；文件任务是否执行以权威 Task/Run fencing 为准。消息仅含 taskNo，不带聊天、密钥或经营载荷。

清理覆盖该实例专用 Redis 队列的 pending、reserved、delayed，依据任务原 expires_at（而非重试时间）删除；不存在的任务、非法专用载荷同样清理，不访问其他实例或普通队列。定时清理必须持续运行并监控清理失败/积压，分批上限 500/队列的调度频率和容量须满足原24小时期限；不能把重试分数、租约或清理失败当作延长留存授权。固定分片文件锁不含 taskNo、账号或 Run，避免锁文件形成长期关联记录。
