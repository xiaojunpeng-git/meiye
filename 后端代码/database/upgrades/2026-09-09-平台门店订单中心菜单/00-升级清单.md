# 平台门店订单中心菜单

- 升级键：`20260909-001-platform-store-order-center-menu`
- 目标：将平台“订单 → 门店订单”的可配置下级菜单调整为 Vue 3 订单中心的八类**只读**记录入口：销售订单、充值订单、退款记录、欠款管理、服务记录、补交记录、赠送记录、卡操作记录。
- 菜单路由：统一进入 `/admin/store/order/center`，使用 `tab` 查询参数切换页签；页面实现必须复用该参数，不得把菜单入口指向需要门店收银员会话的 `/cashier/order-center`。
- 兼容：原“门店订单”“售后订单”“核销记录”三个下级菜单仅设置为隐藏（`is_show=0`）；原菜单 ID、权限标识和路由均保留，历史收藏、旧链接及角色规则继续可用。
- 权限继承：只为已经持有父级“门店订单”（`admin-store-order`）菜单的角色追加八个新只读菜单 ID；不以旧“售后订单”或“核销记录”单项权限反向扩大为全部订单记录权限。原单项角色继续保留原权限和旧路由访问能力。
- 边界：本升级包仅更新 `eb_system_menus`、`eb_system_role.rules` 和升级日志；不修改订单、退款、核销、服务、权益、欠款或任何业务数据。
- 兼容性：MySQL 5.6，幂等执行。若有效父级“门店订单”不是唯一一条，正式升级不会写入菜单、角色或隐藏标记，必须先人工处置菜单重复问题。

执行顺序：`01-升级前检查.sql` → `02-正式升级.sql` → `03-升级后验证.sql`。

菜单和角色规则写入后，必须清除平台 `system_menus` Redis 标签缓存，并让已登录管理员刷新权限（重新登录或刷新菜单）。否则旧权限快照可能短暂保留旧三级菜单或把新路由判为 403；不得用前端放宽路由权限来绕过该刷新步骤。

部署前提：平台 Vue 路由必须提供 `/admin/store/order/center`，并把 `tab` 传给 Vue 3 只读订单中心；本 SQL 不执行前端构建、数据库升级或部署。
