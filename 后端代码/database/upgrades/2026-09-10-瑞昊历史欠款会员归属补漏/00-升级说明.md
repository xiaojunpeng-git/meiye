# 瑞昊历史欠款会员归属补漏

## 目标与问题

旧版 `runner-jsj-debt.php` 以卡产生门店为范围，并额外限制
`map_rh_store.mode='active'`。历史门店产生、但会员和权益已归属到当前门店的欠款因此没有导入。

本迁移逐条读取 `jsj` 的既有购卡及充值欠款来源，移除该额外门店状态限制：

- 购卡欠款：`bd_CardDetail.NonePay` 非零；
- 充值欠款：`SS_CustomerAddMoney.NonePay` 非零，且沿用旧迁移既有的有效充值条件；
- 目标会员：必须存在 `map_rh_customer` 映射；
- 目标门店：优先使用同一卡已存在权益来源订单的当前门店；没有权益来源订单时，使用会员原归属门店的已确认映射。

## 写入规则

- 每条来源使用稳定的 `source_key`，已存在同一 `source_key` 的 `RHD` 欠款不重复写入。
- 有现成权益来源订单的购卡欠款直接回挂该订单及其卡项主明细。
- 充值欠款或没有权益来源订单的购卡欠款写入本批专用迁移订单，不生成经营收款、销售或核销事实。
- 无会员映射、无可解析归属门店且无权益来源订单的来源只计入阻断清单，不写入。

## 执行

默认只预检：

```bash
php 01-执行.php
```

`xinruihao` 写入：

```bash
php 01-执行.php --execute
```

`ruihao` 写入必须显式授权：

```bash
MOHE_REPAIR_ENV_PATH=/www/wwwroot/rh.cc3798.com/.env \
php 01-执行.php --execute --allow-ruihao
```

脚本分批事务写入；任一批失败会回滚该批，已成功批次可按 `source_key` 幂等续跑。
