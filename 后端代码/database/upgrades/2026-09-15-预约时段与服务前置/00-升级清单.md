# 收银 V3 预约时段与服务前置

- 升级键：`20260915-001-cashier-v3-reservation-time-window-v1`
- 预约头表的 `appointment_start_at`、`appointment_end_at` 继续是唯一预约时段权威源；本升级不回写历史预约。
- 新增预约级手艺人安排表，支持没有项目的纯时段预约占用手艺人；项目行中的手艺人 JSON 仅保留为服务项目快照与历史兼容回退。
- 新建或更新预约的最终时段、资源冲突校验、安排表和项目明细均由同一预约事务提交；开始服务仍以预约主表、项目明细和安排表为权威输入。
- 执行顺序：`01-升级前检查.sql`、`02-正式升级.sql`、`03-升级后验证.sql`。
