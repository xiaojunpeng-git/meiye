# 回滚或应急说明

## 推荐的可恢复停用

1. 将 `eb_store_coupon_issue.allow_transfer` 全部设为 `0`，停止新的转赠。
2. 回滚应用代码中的转赠入口和接口。
3. 保留 `eb_store_coupon_transfer` 及其全部记录，不删表、不删记录，用于后续对账和追溯。

```sql
UPDATE `eb_store_coupon_issue` SET `allow_transfer` = 0 WHERE `allow_transfer` <> 0;
```

## 已发生转赠的处理

已发生转赠是业务事实，不应通过回滚 SQL 直接改回归属。如需人工纠错，必须核对券是否已使用、券归属、转出人和接收人，再以独立冲正事件处理；不得删除原转赠记录。
