# 员工学历六档

- 升级键：`20260923-001-employee-education-six-levels`
- 权威源：`eb_employee.education`；一名员工在多门店任职时只保存一份学历。
- 可选值：本科以上、本科、大专、高中、高中以下、其他；空串表示尚未填写，看板暂归入“其他”。
- 变更：新增学历及乐观锁版本列，不回填、不改现有员工资料；编辑由人员完整保存事务写入，并记录变更审计。
- 顺序：备份目标实例 `eb_employee` 与 `eb_employee_change_log` → 执行 `01` → 执行 `02` → 执行 `03` → 发布匹配版本代码并验收。
- 本任务默认只对本地测试库执行；任何客户正式库须另行授权、逐实例备份和验证。
- 回滚：先恢复旧代码与页面；新增列保留以免丢失用户已填学历。需要删除列时，先导出两列及审计并确认没有需要保留的填写记录，单独审批后操作。
