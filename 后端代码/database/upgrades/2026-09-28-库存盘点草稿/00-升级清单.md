# 库存盘点草稿

- Upgrade key: `20260928-001-inventory-stock-count-draft`
- 范围：为门店盘点新增独立草稿表；按当前门店、默认仓和创建人隔离。草稿保存全部选中 SKU 和已填写内容，但不写盘点正式单、库存余额或移动事实。
- 执行：先核对目标客户实例、当前源码版本、迁移版本、共享依赖、备份和回滚点；仅在获得该实例的单独部署与迁移授权后执行 `01-正式升级.sql`。本地测试库执行不代表任何客户实例已升级。
- 确认规则：完成盘点时在同一事务校验草稿版本及内容，仅将有实盘差异的规格写为正式盘点；成功后草稿转为 `CONFIRMED`，不能再次编辑。
- 回滚：上线前可停用新增草稿入口。若已存在草稿或正式盘点，不自动删表或回退库存；先保留数据、停止写入并按单据审计结果制定逐实例恢复方案。
