# 库存 V3 请货受理方升级

- 升级键：`20261002-001-inventory-request-acceptance-party`
- 权威边界：受理方仅用于总部供货请货单的责任路由，不创建仓库、不持有库存、不参与调拨和成本计算。
- 新表：`eb_inventory_stock_request_acceptance_party`
- 单据新增：`acceptance_party_id`、`acceptance_party_name_snapshot`
- 初始目录：总部、办公室、采购部。
- 历史单据保持 `0 / 空快照`，不伪造历史受理归属；升级后新建或修改总部供货请货单必须选择有效受理方。

执行顺序：`01-升级前检查.sql` → 备份目标实例 → `02-正式升级.sql` → `03-升级后验证.sql`。
