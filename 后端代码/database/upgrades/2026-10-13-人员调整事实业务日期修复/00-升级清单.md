# 人员调整事实业务日期修复

- 升级键：`20261013-047-personnel-adjustment-business-date`
- 适用范围：所有已部署订单中心人员调整功能的独立客户实例。
- 代码口径：人员调整改变原订单的人员归属，业绩、导购及销售经理事实沿用原销售订单业务日期；操作单和发生时间保留实际调整日期。
- 历史修复：只处理当前仍生效、由订单人员调整生成且业务日期与原订单不一致的事实。
- 业绩事实：追加一条原错误日期的冲销事实和一条原订单日期的正确正向事实，不覆盖原事实。
- 导购/销售经理事实：按现有状态模型将错误日期行标为 `reversed`，再追加原订单日期的有效事实。
- 执行模式：默认 `--dry-run`；`--test-rollback` 写入后完整验证并回滚；生产备份完成后才允许 `--apply`。

```bash
php 01-执行.php --dry-run ruihao
php 01-执行.php --test-rollback ruihao
php 01-执行.php --apply ruihao
```

本包不自动连接、备份或修改任何远程实例；每个客户实例必须单独授权、备份、执行和登记。
