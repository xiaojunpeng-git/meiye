# 第44轮手机端第三方支付记账

仅本地开发已授权；正式实例执行须另行取得发布授权。前置依赖为会员商城订单及收银记账配置的已建表迁移。按 01、02、03 顺序逐实例执行；02 可重复执行。

代码回滚时保留新增列与字典，不清除已经产生的 third_party 事实或强行改回微信。回退到不认识该记账代码的旧代码前，必须完成事实兼容评估；禁止靠删字典绕过。
