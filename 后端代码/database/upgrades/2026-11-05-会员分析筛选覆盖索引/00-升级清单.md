# 会员分析筛选覆盖索引

目的：会员分析需要先筛选完整授权范围再分页。MySQL 5.7 的宽订单、卡和项目读取需覆盖索引，避免逐行读取宽业务表。仅新增三个普通索引，不改业务事实及历史金额；代码在索引未安装时保留相同口径。

- 正本：同目录 `01-indexes.php`；PHP 7.4 / MySQL 5.7。
- 执行：`php 01-indexes.php --database=明确目标库 --apply`，按实例另行授权、备份、执行和登记。
- 幂等：同名同列跳过；同名不同定义停止。
- 回滚：同脚本 `--rollback`，只删除本轮三个索引，不删除任何业务记录。
- 本轮只在本地 Docker 恢复库验证；正式客户迁移、备份、上线均未执行。
